# The rigid-object half of ABC-130k: the task selection abc_mcap trains on.
#
# These 11 tasks beat the deformable ones (see abc_subset, which is 60% t-shirt folding)
# because a 14-D joint vector does not capture cloth state, so a world model conditioned
# on joints alone cannot fairly be scored on folding.
#
# Each slug names a `data/{split}/{task}/` directory in XDOF/ABC-130k, which is the
# LeRobot task string with spaces replaced by underscores. These come from the 11 tasks in
# preprocessing/abc_rigid/episode_list.json.gz (15477 episodes on the mirror), so both
# generations of the port cover the same tasks and share a stat.json.
#
# The --tasks flag reads this file, splitting on commas and whitespace and ignoring
# comments.
